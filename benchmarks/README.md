# Benchmarks (Planned — Phase 10)

This directory will hold reproducible TinyDB v1.0 micro-benchmarks and end-to-end benchmarks created during Phase 05 and Phase 10, including:

- Sequential scan vs B+ Tree index scan latency and throughput
- Bulk tuple insertion throughput across varying buffer pool sizes
- WAL commit flush latency and crash-recovery replay duration

No benchmarks are implemented yet during repository initialization.
